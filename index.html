PCT_100 化工装置控制器

Chemical Process Control Training Device

ESP32-C3 · FreeRTOS · MQTT · 物联网实训平台

V1.11 · Device ID: PCT_100_039

欢迎使用 PCT_100

PCT_100 是面向嵌入式开发教学与化工过程控制实训的综合实验平台。采用 ESP32-C3-WROOM-02-N4 主控模组，集成温度/光照传感器、多路继电器、OLED 显示屏及 WS2812 全彩指示灯。

支持本地按键操控、传感器自动联动、WiFi 联网配网、MQTT 远程监控以及 FreeRTOS 多线程并行处理。

核心亮点

🌡

温光双传感器

DS18B20 温度 + GL5516 光敏，lux 公式实时换算，自动阈值联动风扇与灯光

🔌

WiFi + MQTT 远程控制

STA 模式联网、Flash 凭据记忆、串口配网、MQTT JSON 指令收发与主动上报

🌈

6 种彩灯灯效

WS2812B 全彩 LED，从正常渐变到严重警报，灯效直观反映设备运行状态

⚙

FreeRTOS 多线程

三线程并行：主线程传感控制 + WiFi/MQTT 通信线程 + LED 指示灯线程

🖥

OLED 实时显示

SH1106 128×64 I2C 屏，5 行信息：模式、温光数值、设备状态、网络连接

⚡

双按键 + 自动模式

KEY1 总电源锁、KEY2 短按循环/长按切模式，自动模式传感器联动
